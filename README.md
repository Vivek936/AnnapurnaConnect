# 🌾 Annapurna Connect

> **Bridging Surplus with Need — One Meal at a Time**

A dignity-first food donation and distribution platform that connects people with surplus food (restaurants, event organizers, households) to individuals and families in need, using smart location-based matching.

## ✨ Features

- 📍 Location-based food matching (map view)
- ⚡ Live impact counters with animation
- 🏆 Donor recognition tiers (Bronze / Silver / Gold)
- 🔍 Smart filter system for food listings
- 📱 Fully mobile responsive
- 🌙 Glassmorphism & modern card-based UI
- 🎯 One-tap claim with pickup time selection

## 🛠️ Tech Stack

`HTML` · `CSS` · `Vanilla JavaScript`
